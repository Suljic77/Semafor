# Štoperica
Implementacija digitalne štoperice razvijena u Flowcode vizualnom programskom okruženju. Projekat demonstrira upravljanje prikazom vremena u realnom vremenu, obradu korisničkih unosa putem tipki te pohranu i ispis izmjerenih vremenskih intervala.
Štoperica prikazuje proteklo vrijeme na digitalnom displeju u formatu MM:SS:ss (minute:sekunde:stotinke). Korisnik upravlja radom štoperice putem četiri namjenska dugmeta. Uz osnovne funkcije pokretanja i zaustavljanja, sistem omogućava bilježenje više krugova koji se prikazuju ispod displeja u nizu — svaki u zasebnoj liniji.

## Funkcionalnost
Dugme   Opis
Start - Pokreće odbrojavanje — vrijeme počinje teći od trenutnog stanja
Stop -  Pauzira štopericu — vrijeme ostaje zamrznuto na displeju
Reset - Vraća štopericu na 00:00:00 i briše sve zapamćene krugove
Prolaz - Pamti trenutno prikazano vrijeme i ispisuje ga ispod displeja u nizu

## Tehnologije
- Flowcode
- PIC mikrokontroler
- Button
- LCD display
